# Worked Designs

Planned case studies:

1. Instagram-like mobile feed
2. Google Drive-like mobile upload and download
3. Spotify-like offline playback
4. Uber-like live trip tracking
5. Slack-like mobile messaging
6. Collaborative mobile document editor

Each case will follow the same structure:

```text
users and scope
→ requirements and budgets
→ data/state model
→ high-level architecture
→ critical flow
→ offline and background behaviour
→ failures and recovery
→ security
→ observability
→ alternatives and trade-offs
```
